# Hadiah Ulang Tahun

A single-page, interactive birthday gift site (opening envelope, gallery, timeline, quiz, cake, letter and final surprise). It is plain HTML/CSS/JS with no build step; personalised content is saved in the browser via `localStorage`.

## Run locally

Open `public/index.html` in a browser, or run `netlify dev`.

## Deploy

Netlify publishes the `public/` directory as-is (see `netlify.toml`).
